# Bảng Đối Chiếu Màn Hình 'Mở Thiệp' (Cover Screen): Real vs Clone Ban Đầu

> Báo cáo tự động theo **Việc 1** trong `docs/requests/antigravity-request-3.md` (commit `6b6963a`).
> Chụp màn Mở thiệp ở trạng thái ban đầu (đợi 3s) ở cả khung nhìn **Mobile (390×844)** và **Desktop (1280×800)**.

## 1. Phương Pháp & Kết Quả Phân Tích Cấu Trúc
- **Thực tế trên chungdoi.com:** 75/75 mẫu đều có màn Mở thiệp riêng (`[data-landing-screenshot-id="invite-envelope"]`).
- **Đặc điểm kiến trúc:**
  - Chia thành **28 khung cấu trúc (`sig`)** khác nhau.
  - Nhóm phổ biến nhất là khung sứ/Baroque mạ vàng (`sig 67993d`, 21 mẫu), hoa lụa mềm (`sig 694b87`, 7 mẫu), tối giản kem nâu (`sig ae1685`, 6 mẫu), Song Long, Song Phụng, Chibi, Cô Ba, Nhật Bình...
  - Mỗi mẫu sở hữu background gradient hoặc ảnh nền riêng, cụm hoa/hoạ tiết nhận diện riêng, và hiệu ứng ambient particles riêng (tim, cánh hoa, chữ Hỷ, lá...).
- **Tình trạng clone hiện tại trước khi dựng Việc 3:**
  - Đa số các mẫu đang dùng phong bì mặc định generic, chưa phản ánh đúng 28 khung cấu trúc thực tế.

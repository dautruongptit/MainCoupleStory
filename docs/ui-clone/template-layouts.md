# Phân loại bố cục 75 mẫu thiệp

Nguồn: HTML trang demo thật (`/vi/mau-thiep/<slug>/demo?open=1`) của cả 75 mẫu, tải ngày 2026-10-17. Phân loại theo **dòng thiết kế** (tên trước dấu " - ", mỗi dòng gồm các biến thể màu) và theo thư mục hoạ tiết (`/images/themes/<thư mục>/`).

**Giới hạn:** chữ ký cấu trúc (băm danh sách thẻ HTML) chỉ là chỉ báo thô. Các biến thể màu của cùng dòng thường có số ảnh trang trí khác nhau nên chữ ký lệch dù cùng bố cục; chỉ Baroque V2 và Hoa Thuỷ Tinh khớp chữ ký hoàn toàn. Chưa so từng cặp bằng mắt, nên việc "các biến thể cùng dòng dùng chung một bố cục" là **giả định cần xác minh** khi dựng.

Tổng: **41 dòng thiết kế**, 75 biến thể, 69 thư mục hoạ tiết riêng (nhiều biến thể mỗi mẫu có thư mục riêng, nên mỗi biến thể cần tải ảnh riêng).

## Đề xuất thứ tự dựng

Ưu tiên theo số biến thể (một lần dựng dùng cho nhiều mẫu nếu bố cục thật sự chung):
1. **Minimalism** (7 biến thể, 2 đã xong phần đầu): hoàn thiện phần thân và thêm Nâu Đậm, Lam Đậm, Đỏ, Xanh, Tím.
2. **Long Phụng** (V1 ×4, V2, V3, V4): V2 xong phần đầu.
3. **Bạch Sứ / Bạch Sứ II / V2** (6 mẫu), **Hoàng Kim / Hoàng Kim II** (5 mẫu), **Baroque / Baroque V2** (5 mẫu), **Hoa Mộc, Hoa Thuỷ Tinh, Vườn Kính, Tơ Duyên, Song Long, Vườn Xuân** (3 mẫu mỗi dòng).
4. Các dòng đơn lẻ (23 dòng, mỗi dòng 1 mẫu) làm sau cùng.

Mỗi dòng cần: dựng lại từ HTML thật, tải ảnh riêng (khoảng 1 đến 2 MB/biến thể, cần bạn đồng ý), chụp so ở 390 px.
